# 쇼핑 리스트

살 것을 적으면 종류별(채소·과일, 생활용품, 전자·디지털, 문구·도서 등)로 알아서 묶어 주는 목록 앱입니다. 서버나 Claude 없이 동작하고, 한 번 열어 두면 인터넷이 약한 곳에서도 열립니다.

- 아이폰: 사파리로 열고 공유 → ‘홈 화면에 추가’. 홈 화면 앱으로 쓰면 목록이 오래 유지됩니다(사파리 탭으로만 쓰면 오래 안 열었을 때 iOS가 저장 내용을 지울 수 있어요).
- 목록은 그 기기에만 저장됩니다. PC와 휴대폰 목록은 따로예요.

## 쓰는 법

- ‘우유 2, 건전지, 수건’처럼 쉼표로 여러 개를 한 번에 넣을 수 있어요. 이름 뒤 숫자는 수량이 됩니다.
- 누르면 ‘담은 것’으로, ‘구매 완료’를 누르면 ‘구매 기록’으로 옮겨져요. 다음엔 구매 기록에서 눌러 바로 다시 추가해요.
- 위쪽 보내기 버튼: 남은 목록을 메시지로 보내거나 복사해요.
- ‘편집’: 분류를 바꾸거나, 목록에서 빼거나, 구매 기록을 지워요.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 앱 전체. 분류 단어 목록은 안의 `CATS` 에 있어요 |
| `sw.js` | 오프라인에서도 열리게 하는 캐시 |
| `manifest.webmanifest`, `icon-*.png` | 홈 화면 아이콘과 이름 |
| `fonts/list-sans.woff2` | 글꼴. Pretendard(SIL OFL 1.1)에서 자주 쓰는 한글 2,350자와 영문만 남기고, 라이선스에 따라 이름을 ‘List Sans’로 바꾼 것. 라이선스 전문은 `fonts/OFL.txt` |

앱을 고친 뒤 휴대폰에 바로 반영이 안 되면 `sw.js` 의 `CACHE` 이름 끝 숫자를 하나 올리세요(`shopping-list-v2`).
