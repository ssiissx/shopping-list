# 쇼핑 리스트

살 것을 날짜별로 적어 두고, 산 것은 언제·어디서·얼마에 샀는지 구매 기록으로 남는 휴대폰용 목록 앱입니다. 서버나 Claude 없이 동작하고, 한 번 열어 두면 인터넷이 약한 곳에서도 바로 열립니다.

- 아이폰: 사파리로 열고 공유 → ‘홈 화면에 추가’. 홈 화면 앱으로 쓰면 목록이 오래 유지됩니다(사파리 탭으로만 쓰면 오래 안 열었을 때 iOS가 저장 내용을 지울 수 있어요).
- 목록은 그 휴대폰에만 저장됩니다.

## 쓰는 법

- 아래 칸에 적고 추가. ‘우유 2, 건전지, 계란 30구’처럼 쉼표로 여러 개를 한 번에 넣을 수 있고, 이름 뒤 숫자는 수량이 됩니다.
- 칸을 누르면 ‘언제든 · 오늘 · 내일 · 날짜’가 떠요. 고른 날짜로 들어가고, 날짜가 지나도 못 산 건 맨 위 ‘지난 것’에 남아요.
- 쇼핑 앱에서 ‘공유 → 복사’한 글이나 링크를 붙여 넣으면 상품명·링크·가게(쿠팡, 네이버 등)·가격이 알아서 채워져요.
- 전에 산 걸 적기 시작하면 아래에 ‘휴지 · 다이소’처럼 떠요. 누르면 지난번 가게·링크까지 같이 들어가요.
- 동그라미를 누르거나 오른쪽으로 밀면 ‘샀어요’, 왼쪽으로 밀면 삭제. 몇 초 동안 ‘되돌리기’가 떠요.
- 줄을 누르면 이름·수량·날짜·가게·링크·가격을 고칠 수 있어요. 가게 칩을 누르면 그 가게 것만 보여요.
- 오른쪽 위 ‘기록’: 산 날짜별로 모아 보고, 찾기로 ‘휴지 3번 · 최저 2,700원(쿠팡)’ 같은 요약을 보고, ‘다시 담기’로 목록에 넣어요.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 앱 전체. 링크 주소 → 가게 이름 목록은 안의 `SHOPS` 에 있어요 |
| `sw.js` | 오프라인에서도 열리게 하는 캐시(저장본 먼저 띄우고 뒤에서 새 버전 받기) |
| `manifest.webmanifest`, `icon-*.png` | 홈 화면 아이콘과 이름 |
| `fonts/list-sans.woff2` | 글꼴. Pretendard(SIL OFL 1.1)에서 자주 쓰는 한글 2,350자와 영문만 남기고, 라이선스에 따라 이름을 ‘List Sans’로 바꾼 것. 라이선스 전문은 `fonts/OFL.txt` |

아이콘 그림은 [Lucide](https://lucide.dev)(ISC 라이선스, © Lucide Icons and Contributors)에서 가져왔어요.

앱을 고친 뒤에는 `sw.js` 의 `CACHE` 이름 끝 숫자를 하나 올리세요(`shopping-list-v3`). 휴대폰은 저장본을 먼저 띄우므로, 새 버전은 올린 뒤 한 번 열었다가 다음에 열 때 보여요.
